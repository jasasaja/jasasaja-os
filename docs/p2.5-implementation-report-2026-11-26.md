- **Tanggal laporan:** 2026-11-26

## 1. Ringkasan hasil

Rute `/handbook` kini memakai `HandbookView` read-only dan tidak lagi menampilkan scaffold "Target Fase 2". Tampilan mengambil kategori, daftar item, dan detail dari `/api/handbook/**`, dengan pencarian `q`, filter kategori, serta badge status editorial. Konten ditampilkan dari versi `Approved` bila ada; bila hanya ada `Draft`, UI menyatakan eksplisit bahwa itu pratinjau dan bukan standar aktif. Rute `projects` tetap memakai `ModuleScaffoldView`.

## 3. Perubahan utama

- `GET /api/auth/me` menentukan keadaan sesi; `401` menampilkan CTA "Masuk dengan Google" dan tombol coba lagi, kegagalan lain memakai `ErrorState`.
- Kategori dimuat dari `/api/handbook/categories` dan dipakai sebagai tombol filter `categoryId`; pencarian memakai `q` dengan debounce 250 ms.
- Daftar item berasal dari `/api/handbook/items` dan menampilkan judul, ringkasan, status, versi, penanda "Standar aktif vX" atau "Belum ada standar aktif", serta waktu pembaruan.
- Detail berasal dari `/api/handbook/items/:id`; enam bagian standar dirender dengan label `Purpose`, `When to use`, `Procedure`, `Checklist`, `Templates/prompts`, dan `Deliverables`, termasuk provenance.
- Resolusi konten: `activeVersion` (`Approved`) dipakai bila ada. Bila tidak ada, versi terbesar dipakai sebagai pratinjau dengan peringatan "bukan standar aktif". Bila ada draf lebih baru dari standar, ditampilkan pemberitahuan informatif.
- Keadaan loading, empty, error, dan success memakai primitive `LoadingState`, `EmptyState`, dan `ErrorState` yang sudah ada; tidak ada primitive atau dependency baru.
- Tidak ada tombol create/edit/approve dan tidak ada editor blok pada UI.

## 7. Risiko atau masalah yang ditemukan

- **Verifikasi visual belum dilakukan.** Build dan tinjauan bundle membuktikan kode masuk ke artifact, tetapi tidak membuktikan tampilan/interaksi aktual di browser. Ini known gap yang disengaja.
- **Filter kategori memakai tombol, bukan `Select`.** Untuk jumlah kategori kecil ini acceptable; bila kategori banyak, daftar bisa panjang dan perlu slice penyempurnaan.
- **Debounce 250 ms belum diuji secara interaktif.** Logika ada, tetapi buktinya statis; tidak ada test UI otomatis.
- **Drift partial unique index** dan **belum ada automated backend test** tetap terbuka dari slice sebelumnya.
- **Route `projects` masih scaffold.** Sesuai scope P2.5, tidak diubah.
