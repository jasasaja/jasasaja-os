## 7. Risiko atau masalah yang ditemukan

- **Data contoh, bukan standar produksi.** Konten `[SEED-P2]` sengaja diberi label jelas agar tidak disalahartikan sebagai kebijakan engineering final.
- **UI belum menampilkan paket ini.** Rute `/handbook` masih scaffold; bukti P2.4 berhenti di API. Ini menjadi fokus P2.5.
- **`approvedAt` memakai `new Date()` saat insert pertama.** Idempotensinya bergantung pada `onConflictDoNothing`; bila ID seed diubah atau dihapus lalu di-seed ulang, `approvedAt` akan berbeda. Ini dapat diterima untuk seed development dan dicatat.
- **Drift partial unique index** antara `0000_init.sql` dan deklarasi Drizzle masih terbuka; tidak ada migrasi baru dibuat.
- **Belum ada automated backend test.** Seed dan endpoint kini saling bergantung; smoke manual saja tidak cukup untuk klaim hardening.
