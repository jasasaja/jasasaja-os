- **CI hijau hanya untuk `7d46927`** — dokumen P4.1 tidak termasuk run `45956782960` dan perlu commit + run baru.
- **Warning `EBADENGINE` `cookie@2.0.2`** (butuh Node ≥22, CI memakai Node 20) — non-blocking saat ini, tidak diubah tanpa persetujuan dependency.
- **Warning Vite `__dirname`** di `vite.config.ts:22` — non-blocking, tidak diubah pada slice ini.
- **Branch protection / required checks belum diverifikasi atau dikonfigurasi** — CI hijau belum menjadi gate wajib merge.
- **CI belum menjalankan automated backend/DB/UI test** — 23 test yang lulus adalah test frontend existing; rencana penutupan ada di P4.2.
- **Commit/push bergantung manual pengguna** via GitHub Desktop karena kendala autentikasi di environment agent.
- Gap Phase 1–3 dari [gate penerimaan](./phase-1-3-acceptance-gate-2026-11-27.md) tetap berlaku dan tidak dihapus oleh slice ini (browser/a11y/responsive, `stage`/`status`, E2E kontinu, OD-002 constraint deploy, dll.).
