## 1. Ringkasan hasil

Dua endpoint baca project baru tersedia dan terdaftar di Fastify: `GET /api/projects` dan `GET /api/projects/:projectId`. Daftar project mendukung filter `status` dan `q`; detail mengembalikan milestone, task, tanggal format `YYYY-MM-DD`, dan ringkasan item handbook untuk `handbookItemId`. Referensi `lessonId` sengaja dikembalikan sebagai UUID mentah dan tidak di-resolve. Route, komponen, dan endpoint learning tidak disentuh pada slice ini, sesuai instruksi eksplisit pengguna.

## 3. Perubahan utama

- `GET /api/projects`: mengembalikan `{ data: [...] }` berisi `id`, `name`, `description`, `status`, `milestoneCount`, `taskCount`, `createdAt`, `updatedAt`.
- `GET /api/projects/:projectId`: mengembalikan `data` project yang sama plus array `milestones` dan `tasks`.
- Filter `q` memakai `ilike` pada `name` dan `description`, case-insensitive; wildcard LIKE (`%`, `_`, `\`) dinetralisir menjadi spasi seperti pola P2.1.
- Filter `status` memakai enum schema: `Planned`, `Active`, `Completed`, `Archived`.
- Detail task memuat `dueDate` dan milestone memuat `targetDate` dalam format `YYYY-MM-DD` sesuai C2.
- `handbookItemId` di-resolve menjadi ringkasan `{ id, title, summary, status, version, hasApprovedVersion }` dengan membaca tabel handbook dari shared DB schema; tidak ada import file internal modul handbook.
- `lessonId` tetap dikembalikan apa adanya (UUID atau `null`) tanpa lookup modul learning.
- Semua endpoint berada di balik guard owner existing; error envelope memakai `AppError`/Zod yang sudah ada.

## 7. Risiko atau masalah yang ditemukan

- **Istilah `stage` belum tersedia di schema.** API memakai `status` sebagai label tahap proyek; kontrak `docs/api-contract.md` §6.4 masih memakai `stage` dan tetap `Proposed`. Tidak ada migrasi/schema change pada slice ini.
- **Referensi `lessonId` belum berguna di UI/API.** Ini keputusan sadar sesuai instruksi "lewati learning", bukan data rusak.
- **Belum ada pagination `meta`.** Respons mengikuti pola `{ data: [...] }` seperti modul learning/handbook; gap ini terbawa dari Phase 2.
- **Resolusi handbook membaca shared DB schema.** Tidak ada import file internal modul handbook, tetapi tetap perlu dijaga agar tidak berubah menjadi coupling modul saat P3.3.
- **Belum ada automated backend test.** Endpoint project baru hanya diverifikasi lewat smoke manual.
- **Working tree tetap uncommitted.** Perubahan Phase 1, Phase 2, dan Phase 3 belum di-commit; tidak ada reset/checkout destruktif.
