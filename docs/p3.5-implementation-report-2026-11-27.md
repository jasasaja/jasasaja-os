# Laporan Task — P3.5: Project UI MVP + deep-link Handbook

- **Phase / Slice:** `P3.5`
- **Task ID / nama:** `P3.5 — Project UI MVP + deep-link Handbook`
- **Goal:** Rute `/projects` menampilkan data nyata dari API; task dengan referensi handbook dapat dibuka ke item handbook terkait. Rute `/handbook` menerima deep-link `?item=<id>` untuk membuka detail langsung.
- **Tanggal laporan:** 2026-11-27
- **Status laporan:** `Done`
- **Status task di backlog:** `Done` (local, verified with known gap: browser manual ditunda)

## 1. Ringkasan hasil

Rute `/projects` kini memakai `ProjectsView` baru yang sepenuhnya membaca data dari `/api/projects/**` melalui `apiFetch`. Daftar project mendukung pencarian dan filter status; detail project menampilkan milestone, task, dan ringkasan handbook dari API. Tombol "Buka handbook" pada task melakukan navigasi SPA ke `/handbook?item=<id>`. `HandbookView` kini membaca querystring tersebut saat mount, menyinkronkannya lewat `popstate`, dan menulis/menghapusnya saat item dibuka atau ditutup. Tidak ada konten project hard-coded di bundle.

## 3. Perubahan utama

- `ProjectsView` memanggil `/api/auth/me`, `/api/projects?q&status`, dan `/api/projects/:projectId`; tidak ada data contoh yang ditanam di komponen.
- State UI: auth loading/error (termasuk 401 → ajakan login), daftar loading/empty/error/success, detail loading/error/success; tombol "Muat Ulang" dan "Hapus Filter" tersedia.
- Detail project menampilkan badge status, jumlah milestone/task, daftar milestone (`targetDate` format `YYYY-MM-DD`), dan daftar task (`dueDate`, milestone terkait, ringkasan handbook).
- Ringkasan handbook pada task menampilkan judul, status, versi, dan tombol "Buka handbook" yang memanggil `onOpenHandbookItem(handbookItem.id)`; referensi `lessonId` sengaja tidak ditampilkan.
- `App.tsx` menyimpan `pathname + search` sebagai state lokasi agar `resolveRoute` tetap bekerja sementara querystring deep-link tidak hilang pada `popstate`.
- `HandbookView` memakai `readDeepLinkItemId()` saat inisialisasi, `writeDeepLinkItemId()` dengan `replaceState` saat membuka/menutup item, serta listener `popstate` untuk perubahan query.
- Cabang `learning`, `dashboard`, dan `settings` di `App.tsx` tidak diubah pada slice ini; tidak ada endpoint atau komponen learning yang disentuh.

## 7. Risiko atau masalah yang ditemukan

- **Browser/a11y/responsive belum diverifikasi manual.** Ini gap yang disadari; build dan typecheck tidak membuktikan perilaku klik/focus nyata.
- **Sinkronisasi query pada klik nav yang sama.** Jika pengguna sudah berada di `/handbook?item=<id>` lalu mengklik item navigasi Handbook yang sama, daftar tidak otomatis berubah karena path tidak berganti; tombol "Semua Item" tetap berfungsi. Perbaikan yang lebih menyeluruh memerlukan propagasi query sebagai prop dan sengaja tidak dimasukkan agar perubahan App tetap kecil.
- **`ModuleScaffoldView` tidak lagi dipakai `App.tsx`.** File dibiarkan utuh (tidak dihapus) sebagai bagian dari working tree lama; tidak ada penghapusan destruktif.
- **Belum ada test backend otomatis.** Modul API project sudah delapan handler dengan smoke manual sebagai bukti lokal.
- **Working tree tetap uncommitted.** Perubahan Phase 1–3 belum di-commit; tidak ada reset/checkout/stash destruktif.
