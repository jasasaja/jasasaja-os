## 7. Risiko atau masalah yang ditemukan

- **Seed bersifat development.** Baris `[SEED-P3]` sengaja tetap ada di DB development setelah verifikasi; bukan standar produksi dan tidak boleh dipakai sebagai konten final tanpa keputusan terpisah.
- **Referensi handbook bergantung seed `[SEED-P2]`.** Bila seed P2 dihapus atau diubah statusnya, ringkasan pada detail project berubah; tidak ada FK lintas modul.
- **`lessonId` kosong.** Ini konsekuensi sadar dari keputusan "lewati learning", bukan data rusak.
- **Belum ada UI yang menampilkan paket ini.** Rute `/projects` masih scaffold; P3.5 akan menghubungkan data nyata.
- **Working tree tetap uncommitted.** Perubahan Phase 1–3 belum di-commit; tidak ada reset/checkout/stash destruktif.
