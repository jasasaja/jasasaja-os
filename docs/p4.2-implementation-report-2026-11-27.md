## 4. Keputusan teknis

- **Route-level Fastify inject + DB mock**, bukan integration test DB nyata. Ini sesuai scope minimum dan menghindari dependency/infra baru.
- **Mock di level `pg.Pool.prototype.query/connect/end`** dengan queue expectation; Drizzle node-postgres tetap menghasilkan SQL nyata sehingga query order/pattern ikut terverifikasi ringan.
- **Tidak ada mock auth guard untuk route ini** karena guard dipasang di `app.ts` `preHandler`; route tests mendaftarkan route langsung dengan error handler yang sama. Scope auth/guard E2E tetap di luar P4.2.
- **Tidak ada perubahan dependency**. Lockfile tidak berubah.
