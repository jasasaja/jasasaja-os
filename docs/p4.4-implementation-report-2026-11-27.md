## 3. Skenario kontinu yang dibuktikan

Test: `server/src/modules/e2e-handbook-project.routes.test.ts`

Alur berurutan dalam satu test:
1. **Create handbook item** (Draft v1) — `POST /api/handbook/items` → 201.
2. **Approve handbook version** — `POST /api/handbook/items/:id/approve` → 200, status `Approved`.
3. **Create project** — `POST /api/projects` → 201.
4. **Create task with handbook reference** — `POST /api/projects/:projectId/tasks` dengan `handbookItemId` → 201; response memuat `handbookItem.hasApprovedVersion=true`, `status=Approved`.
5. **Read project detail** — `GET /api/projects/:projectId` → 200; task memuat data handbook yang dapat dipakai deep-link `/handbook?item=<id>`.

Ini mock-backed route-level continuous flow (Fastify inject + DB mock queue), bukan integration test PostgreSQL nyata.
